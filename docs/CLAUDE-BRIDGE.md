# Мост Claude: Claude Code работает с открытым редактором

STB Editor может поднять локальный MCP-сервер, и тогда Claude Code на этом же компьютере работает с редактором напрямую:
смотрит в окно рендера, ставит камеру, находит и выделяет объекты, двигает и ставит их, читает и меняет поля записей,
ищет, смотрит «Где используется» и конфиги фреймворков, оставляет пометки поверх окна. Пользователь отмечает места для
Claude клавишей **K**.

**По умолчанию выключено.** Включается в «Вид → Настройки → Claude» (или «Вид → Claude...»).

## Подключение

1. «Вид → Настройки» → раздел Claude → «Разрешить Claude Code работать с редактором». Ниже появится адрес
   `http://127.0.0.1:47110/mcp` (порт меняется там же).
2. Один раз в терминале:

   ```
   claude mcp add --scope user --transport http stb-editor http://127.0.0.1:47110/mcp
   ```

3. В Claude Code инструменты появятся как `stb-editor` (`--scope user` — в любой папке). Редактор должен быть запущен и с
   загруженными данными.

Или прямо в редакторе: «Вид → Claude...» → «Спросить Claude» — окно запускает ваш Claude Code (`claude -p`) только с
инструментами этого редактора, показывает ответы и какие инструменты он вызывал; разговор продолжается, «Новый разговор»
начинает заново. Нужен установленный и залогиненный Claude Code; расходует ваш аккаунт Claude.

## Что умеет

| Инструмент | Что делает |
|---|---|
| `get_status` | что открыто: плагины, активный файл, несохранённое, ячейка, камера, выделенное, метки |
| `screenshot` | снимок окна рендера (с пометками и текстом в углу; ждёт загрузки моделей и текстур) |
| `set_camera`, `look_at` | камера в точку / на объект с расстояния, курса и наклона |
| `load_cell` | загрузить ячейку по EditorID / FormID или мир + сетка |
| `list_objects`, `pick` | объекты рядом с камерой; что под точкой снимка |
| `select` | выделить объекты (пользователь видит выделение, Инспектор — первый) |
| `move_objects`, `place_object`, `delete_objects` | сдвиг / поворот / масштаб, новый объект, удаление — каждое одним шагом Ctrl+Z |
| `undo` | отменить / вернуть шаги |
| `find_records`, `get_record`, `set_field` | поиск записей, все поля записи, поле по пути (`Name`, `Configuration.HealthOffset`, `Keywords[1]`) |
| `use_info`, `framework_info` | кто ссылается и где стоит; SPID / KID / BOS…, у NPC — что даёт SPID |
| `annotate`, `clear_annotations` | пометки Claude поверх окна (кружок и текст у объекта или точки) |
| `get_user_marks` | метки пользователя (K) с заметками, ячейкой и объектом под ними |
| `propose_changes`, `proposal_status` | предложить сдвиги / повороты / удаления, не делая их: объекты показаны на новых местах (подсвечены), пользователь применяет (Enter или «Применить», одним шагом отмены) или отклоняет (Backspace); можно дождаться решения |
| `get_journal` | лог сессии (сначала предупреждения и ошибки), история отмены, последний отчёт о вылете |
| `run_script` | C#-скрипт как в окне «Скрипты»; его правки записей — один шаг отмены |

## Безопасность

- Сервер слушает только `127.0.0.1` — подключиться могут программы этого компьютера; запросы из браузера с чужого сайта
  (заголовок Origin) отклоняются.
- **Claude ничего не сохраняет:** все изменения — обычные шаги отмены в редакторе, сохраняет пользователь (Ctrl+S).
- «Claude может вносить изменения» снимает с Claude право править (останутся просмотр, поиск, снимки, пометки и
  предложения — их применяет только пользователь).
- Окно «Вид → Claude...» показывает последние вызовы Claude — что он смотрел и что менял.

## Для разработчиков

`Services/ClaudeBridge.cs` — HTTP (Streamable HTTP, ответы JSON, без SSE) и JSON-RPC: `initialize`, `ping`, `tools/list`,
`tools/call`. Вызовы инструментов кладутся в очередь и выполняются в UI-потоке между кадрами (`Pump` из `EditorApp`),
`MainWindow.Wake` будит простаивающий цикл. Инструменты — `Services/ClaudeTools.cs`; со стороны окна рендера —
`Panels/RenderWindow.Claude.cs` (снимок: готовый кадр окна, вырезанный по области вида — `ServeWindowShots` из Program;
пометки, метки, правки через `Commit`). Проверка без Claude Code:

```
curl -s -X POST http://127.0.0.1:47110/mcp -H "Content-Type: application/json" -d "{\"jsonrpc\":\"2.0\",\"id\":1,\"method\":\"tools/call\",\"params\":{\"name\":\"get_status\",\"arguments\":{}}}"
```
